## How to Use This Repository

1. Choose a pattern from the table above.
2. Open its folder using the clickable link.
3. Read the explanation and understand the pointer/algorithm movements.
4. Study the code and dry-run it with the provided examples.
5. Solve the practice problems independently.
6. Track your progress and revisit problems you could not solve.

## What Each Pattern Folder Should Contain

Use this consistent structure for every new pattern:

```text
01_RiseAhead_Two_Pointers/
├── README.md          # Pattern overview and navigation
├── notes/             # Detailed learning notes / PDF
├── examples/          # Dry runs and visual examples
└── practice/          # Problem list and solutions
```

The folder link in the Pattern Library is relative to this root README. Keep the folder name unchanged, or update the link if you rename the folder.

## Add a New Pattern

When a new pattern folder is added to the repository, add a row to the Pattern Library table using a relative GitHub link:

```markdown
| 02 | Sliding Window | [Open Sliding Window](./02_RiseAhead_Sliding_Window/) | Available |
```

Repeat for each pattern. Relative links work across GitHub repositories and do not depend on a hard-coded repository URL.
